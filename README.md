# Personal Website

A minimalist, dark-themed personal website built with HTML, CSS, and Vanilla JavaScript.

## Features
* Scroll-triggered section animation.
* header scaling on scroll.
* Silly idea generator.
* Smooth scroll Back-to-Top button.

## Tech Stack
* HTML5
* CSS3
* JavaScript (Vanilla)
